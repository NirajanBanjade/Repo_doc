# Repo Impact Map

Explore a public GitHub repository as an interactive dependency graph and use AI to understand the impact of code changes.

## Development

You need Bun installed and an OpenAI API key for the AI assistant.

```sh
git clone <this-repository-url>
cd <repository-name>
bun install
OPENAI_API_KEY=<your-key> bun run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- OpenAI API
